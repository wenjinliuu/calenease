# 省心日历 · CalenEase

排班、日程、工时一本账，专门为不按星期工作的人设计（原名「循环班表」）。
`ios/` 是 iOS 原生版（SwiftUI + Liquid Glass），App Store 名称「省心日历-循环班表」，
桌面显示「省心日历」。网页版采用手机优先设计，可作为 PWA 添加到桌面使用。
两端共用同一套排班与工时规则，备份文件可以互相导入，旧版「循环班表」的备份照样能导入。

## 功能

- 自定义班次对象：名称、简称、颜色、时间、跨天、休息属性、默认工时均可修改
- 每天一个主要班次，可附加多个职责标签
- 工时统计与加班统计彼此解耦，可独立关闭
- 支持标准工时、综合计算工时、不定时工时、自定义和手动记录
- 日历、统计、设置三栏结构，月度排班与工时展望集中在日历页
- 内置 4白2休4夜2休、做二休二、3上4休 / 4上3休和常见三班倒模板
- 循环模板保存班次 ID 序列，可使用任意自定义班次，并会跨年度持续生成
- 制造业、医疗护理、交通运输、公共安全、服务业等职业预设只影响起始推荐，不限制功能
- 区间批量修改：依次选择开始日和结束日，统一修改整段日期
- 日历逐日调整班次、职责标签、工时和备注，单日覆盖不会打断后续循环
- 自动识别每年 13 个法定节假日
- 按“周一至周五 × 日标准工时 − 落在工作日的法定节假日”自动推算 2025—2050 年每月基本工时
- 预计基本工时支持逐月手动修正，以适配每年另行发布的调休和补班安排
- 统计页面会根据功能开关切换为仅排班、仅工时或工时与加班视图
- JSON 数据备份导出与导入恢复
- 手机端液态玻璃界面和桌面模式

## 数据说明

当前版本的数据保存在设备本机，不会上传到服务器。网页版写入浏览器本机存储，
iOS 版写入应用沙盒 Application Support 下的 `calenease.json`（旧版文件 `shift-ledger.json` 首次打开时自动改名沿用）。数据结构版本为 v2；旧版 `day / night / rest` 数据会在首次打开时自动迁移。更换设备或清除浏览器数据前，请先在设置页导出 JSON 备份。

首次使用保持空日历，不会自动生成任何班次。可从循环排班模板开始，也可以逐日手动记录。

法定节假日判定以《全国年节及纪念日放假办法》规定的 13 个法定日为准。农历日期和清明节气由 `lunar-typescript` 在本机计算。未来年度的调休与补班并非固定规则，因此自动值会明确标记为推算值，并保留手动修正入口。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目使用 Next.js 静态导出，Netlify 发布目录为 `out`。`main` 分支更新后，Netlify 会自动重新构建和发布。

## iOS 版

`ios/` 下是 SwiftUI 原生实现（XcodeGen 管理工程，`.xcodeproj` 不入库）：

```bash
cd ios
brew install xcodegen
./Scripts/bootstrap.sh --open
```

Bundle ID 为 `com.wenjinliu.calenease`，仅 iPhone、仅竖屏，最低 iOS 26。
排班、工时、加班与节假日规则在 `ios/CalenEase/Rules/` 下逐条对应网页版
`app/lib/`，单元测试照着 `tests/` 写，两端结论必须一致；JSON 备份可以互导。

工程说明见 [`ios/README.md`](ios/README.md)，签名、元数据、审核与发版流程见
[`docs/ios-release.md`](docs/ios-release.md)，隐私政策页面在 `/privacy/`。
