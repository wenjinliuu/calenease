全部关掉就只剩日期和一块颜色。24 小时条在这里叫「时段条」——它是方案 C 的特征，但不是必需品。

当前对比度

每个班次的「底色 / 文字」实算值。低于 4.5:1 会标红——浓度拉太高时文字色会自动压暗来补，但实心档下有些色相补不回来。

四档浓度

同一组色，从淡染到实心。之前那版默认停在最淡的一档，所以显得寡。第三档「浓」是多数人说的"苹果那种鲜艳"——颜色已经占满格子，文字还稳稳在 4.5:1 以上。

07
几条不能动的

  

    
文字色跟着底色走，不是固定值。
浓度每升一档，文字色就得压暗一档。写死一个 .white 是现在代码里最大的问题——九个班次色刷白字全部不达标，systemYellow 上只有 1.51:1。

    
白班和夜班必须在明度上也拉开。
不能只靠色相。橙和靛在色相上差很多，但如果两个都调到同样的明度，缩略图上整月就是一片均匀的花。明度拉开之后，轮转节奏在缩略图上才看得出来。

    
休息和请假不占色位。
它们是"没有班"，不是"第 N 个班次"。用 systemGray 家族，把六个彩色位全留给真正要区分的工作班次。

    
底色用冷灰，不能用暖奶油。
浅色 #F2F2F7 + 白卡，深色纯黑 + #1C1C1E。底色一偏暖，再鲜艳的系统色压上去也立刻显旧。
