06

推荐组合

系统色 + 排版 二（淡染卡）

  1. 配色选「系统色」：直接用 iOS 的 systemOrange / systemIndigo / systemMint / systemPink / systemPurple / systemGreen。用户在别的 App 里已经认得这几个色，不需要重新学；而且以后换成 Color.orange 这种语义色，深浅色两套是系统自动给的。
  2. 排版选二（淡染卡）：格子底是班次色 13% 淡染，简称用同色深阶，24 小时条用满色。这是三层里唯一「整格都带色」的，最接近你说的多彩，而且对比度全部 ≥ 4.6:1。
  3. 休息和请假不占色位：用 systemGray 家族 + 空心条。六个色位全留给真正要区分的工作班次。
  4. 渐变只允许出现在 24 小时条上，而且必须同色相内渐变（橙深→橙浅，不是橙→粉）。现在代码里 gradientEnd 把蓝收到紫、黄收到橙，尾色正好是别的班次的身份色，这个要删掉。
  5. 底色换成冷灰：#F2F2F7 分组底 + 纯白卡，深色模式是纯黑 #000 + #1C1C1E 卡。直接用 systemGroupedBackground 那一族，不要自己调暖灰。
  6. 字体不用管：iOS 上就是 SF Pro，数字全部打开 monospacedDigit()，格子里的日期和工时才不会跳。
