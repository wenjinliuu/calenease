# 日历与统计页设计提案（2026-09）

`proposal-2026-09.html` 是一份可交互的改版提案，直接用浏览器打开即可。
页面顶部的控制条可以切换配色、格内信息开关和深浅色，下方所有演示会同步重绘。

内容分五节：

| 节 | 内容 |
| --- | --- |
| 01 现状问题 | 十条可指到代码的问题，对比度按 WCAG 公式实算 |
| 02 配色地基 | 昼夜 / 素墨 / 工牌 三套完整 token，含明暗两套色值 |
| 03 日历方案 | 实心色块 / 左侧色条 / 24 小时条 / 极简点阵，同一份 9 月排班 |
| 04 统计页图形 | 进度、概览卡片、月度走势、班次构成各给现状与改法对照 |
| 05 推荐组合 | 一套推荐搭配 + 按文件拆的改动清单 |

## 几条结论

- **班次胶囊上的白字九种班次色全部不达标**：白班黄 `#f6c543` 对白字只有 1.62:1，
  连界面元素的 3:1 都差很远。改法是班次色改成 `(fill, ink, rail)` 成对 token，
  对比度在色板层就保证到 4.5:1 以上。
- **`gradientEnd` 把蓝收到紫、黄收到橙**，而紫是晚班色、橙是早班色，
  渐变尾色正好撞上别的班次身份。建议删掉渐变。
- **内置班次有三组重色**：夜班／小夜、晚班／大夜／责班、其他／门诊。
- **新色板六色**（黄→紫→青→橙→蓝→红）过了色盲分离度校验：
  相邻色对 OKLab ΔE 最差 9.2（阈值 8），普通视觉最差 27.6（阈值 15），明暗两套都过。
  休息、请假这类不计工时的状态不占色位，用中性灰区分。
- **统计页的基本 / 计划 / 已完成 / 加班单位都是小时**，属于同一把尺上的四个位置，
  不该用四种色相。推荐用子弹图：一条刻度同时放下四个量。
- **离散月份不要用 `.monotone` 平滑**，改柱状 + 每月目标线。

## 来源

配色校验用了 `dataviz` skill 的 `validate_palette.js`（OKLab ΔE + WCAG 对比度）；
图形选型参考了 `nextlevelbuilder/ui-ux-pro-max-skill` 的 charts / colors / ux 数据集；
SwiftUI 侧的 Charts 与 Liquid Glass 用法参考 `AvdLee/SwiftUI-Agent-Skill`。
`twostraws/Swift-Agent-Skills` 是一份索引，本身不含设计规则。

# 南瓜与靛（2026-09 第七版 · 当前）

`palette-apple.html`。配色选定 **南瓜靛**（白班 `#F06E15` / 夜班 `#5856D6`），
排布选定 **排法一**（色标 + 工时同行，格子不填底色）。

## 色标里的字：深色模式下黑字更好

深色模式必须把色标提亮（纯黑底上放原色色块会显脏、边缘发糊），
提亮之后白字的余量就没了：

| 深色模式色标 | 白字 | 黑字 |
| --- | --- | --- |
| 白班 `#EE6D15` | 3.07 | **6.83** |
| 夜班 `#7076DD` | 3.94 | **5.32** |
| 早班 `#00B09F` | 2.72 ❌ | **7.71** |
| 中班 `#E6419E` | 3.74 | **5.61** |

再提亮到 OKLCH L 0.78 配黑字能到 **10:1**，色块也更鲜。页面给了三种做法可切：
一律白字 / 一律黑字（提亮）/ 浅色白·深色黑。

## 一天挂多个职责标签

一格 46pt，色标 13 + 工时 17 + 两道间距 = 34pt，**同一行只放得下一个标签**。
多个时四种做法：

- **首个 + 圆点**：第一个写字，其余每个一颗 4px 圆点。不换行不加高。
- **独占第二行**：标签整体挪到第三行，最多三个，每个都看得清。
- **工时让位**：有标签时不显示工时，位置全让给标签。
- **首个 + 角标数**：像「责³」。最省地方，但要点开才知道另外两个是什么。

## 格子状态全集

页面第 04 节列了十八种状态，包括容易漏掉的：两字简称（「大夜」撑成胶囊）、
小数工时（11.5h 最宽）、节假日当天还要上班（红字 + 正常色标）、
有备注的日子（左上角一点）、请假（描边灰）、未排班（只有浅灰数字）。

# 橙与蓝 · 白字版（2026-09 第六版）

`palette-apple.html`。排法一定稿：色标 + 工时同行，格子不填底色。
色标里**一律白字**（原先白班用的是同色深阶字，夜班才是白字，不统一）。

## 白字带来的硬约束

色标是 14px 方块，想让里面的白字成立，橙就必须往红的方向推：

| 橙 | 原色白字 | 压到白字 3:1 后 |
| --- | --- | --- |
| systemYellow `#FFCC00` | 1.51 | `#B59000` 已变芥末 |
| systemOrange `#FF9500` | 2.20 | `#D87D00` 已发土 |
| 琥珀 `#FFAA00` | 1.91 | `#CB8600` 发土 |
| **朱橙 `#FF5A1F`** | **3.12 原色即可** | 不用改 |
| **南瓜 `#F97316`** | 2.80 | `#F06E15` 几乎不变 |

越黄的橙越扛不住白字，越红的橙天生够暗。所以八组配对全部落在朱橙 / 南瓜一族，
前六组按 3:1（图形门槛）挑，后两组按 4.5:1（正文门槛）挑。

## 新增：职责标签

备班、责班、带教、门诊这类职责是独立于班次的第二层信息，一天可挂多个，
所以**必须比班次标弱一档**。四种画法（实心小方块 / 纯色字 / 描边方块 / 淡染方块）
× 四个位置（跟在工时后 / 另起一行 / 日期左上角 / 班次标右上角角标）。
推荐纯色字——实心方块是班次、无底彩字是职责，层级差最大。

## 新增：休 / 节假日 / 调休

三种性质分开，颜色分工：

- **普通休息日**：灰。一个月十天，必须能退到背景里。
- **法定节假日**：红 `#D70015`（比 systemRed 深一阶，小字才压得住白底）。一年十三天。
- **调休上班**：绿 `#248A3D`。含义与节假日相反——本该休却要上。

## 宽度实测

iPhone 上一格约 46pt。色标 13 + 工时「12h」约 17 + 职责标签 8，
加两道 2pt 间距刚好 42pt——塞得进但没余量。所以同行方案里工时压到 10.5px、
色标压到 13px；要留余量就把标签挪到左上角或另起一行。

# 橙与蓝（2026-09 第五版）

`palette-apple.html`。方向已定，两件事锁死：

- **格子结构**：留白式——不给格子任何底色，日期数字（23px / weight 550）做主角，
  休息日整个数字退成三级灰，颜色只剩一枚 14px 小色标。
- **白班 = 橙，夜班 = 蓝**。这两个色认知成本最低，不再往外扩展。

降饱和度的浊色方案全部删除。剩下三个维度可调：

| 维度 | 选项 |
| --- | --- |
| 橙 × 蓝 | iOS 原色 / 琥珀深蓝 / 金与天青 / 落日 / 参考同款 / 橙与靛 |
| 其余班次 | 暖冷分组 / 同族延伸 / 多彩 |
| 色标排法 | 方块标+工时 / 方块居中 / 大方块 / 描边方块 / 胶囊 / 贴数字左边 / 下划线 / 只有方块 |

橙全部落在 OKLCH 色相 60–75°，蓝落在 230–265°，明度差都拉开了。

## 「其余班次」的三种跟法

- **暖冷分组**：白天上班一律暖色（早班黄、中班粉），夜里上班一律冷色（晚班紫）。规则最好记。
- **同族延伸**：不引入新色相，只在橙族蓝族里取深浅阶。一致性最高，班次多时不好分。
- **多彩**：剩下四个色位直接拉开（青 / 粉 / 紫 / 绿）。医护、公共安全这类班次多的用这套。

## 工时数字的颜色有三档

参考图里「11.5h」用的是班次原色，但橙色原色压在白底上只有 **2.6:1**，
达不到正文门槛。所以给了三档：**班次色**（同色相压到 4.5:1 的深一阶，橙会偏琥珀）、
**原色**（参考图那种效果，不达标）、**文字色**（最稳）。页面顶栏可以直接切。

色标里的字同理：白字压在 systemOrange 上只有 2.20:1，所以用的是
**同色相压暗的版本**——橙底配深琥珀字，看上去还是一个颜色的深浅两阶。

# 留白与满色（2026-09 第四版）

`palette-apple.html`。前三版的淡色一直显土，根因是**算法**：把系统色和白色在
sRGB 里插值，白一兑进去彩度就被稀释——橙变粉橘 `#FFC26B`、绿变灰绿 `#89DF9F`。
这一版换成 **OKLCH：只抬明度，彩度顶在该明度下 sRGB 能给的最大值**，
同一档浓度出来是 `#EB8900` 和 `#33C357`。

| 系统色 | 兑白 42%（旧） | OKLCH 保彩度 L=0.80（新） |
| --- | --- | --- |
| 橙 `#FF9500` | `#FFC26B` | `#EB8900` |
| 绿 `#34C759` | `#89DF9F` | `#33C357` |
| 薄荷 `#00C7BE` | `#6BDFD9` | `#00BDB4` |

顺带的发现：苹果系统色里橙黄天生亮（OKLCH L 0.77 / 0.87），靛蓝天生暗（0.53 / 0.60）。
**全部按满饱和度用时，白班自动是亮块、夜班自动是暗块**，昼夜感是色相本身带来的，
不用另外设计。

## 七种格子

前三种给格子上色：整格满色 / 圆角色块 / 格内胶囊。
后四种一点底色都不给，靠字号和留白撑（参考"安心记加班"那一类的排法）：
大字 + 方块标 / 圆点 / 下划线 / 微时段轴。每种都有整屏预览，
含月份切换、周栏、网格和底部汇总卡。

## 文字色

不再是黑或白，而是**同色相压暗或提亮的版本**，按底色实时算，压到 4.5:1 才停。
整块看上去是一个颜色的深浅两阶，比黑字白字更整。

注意：SwiftUI 里 `color.opacity(0.15)` 压在白底上等价于 mix 白，
出来还是奶油色。要淡色就预先算好 hex 存进色板，不要在运行时靠透明度凑。

# 配色台（2026-09 第三版，已被第四版取代）

`palette-apple.html`。第二版默认停在 13% 淡染，被指"不够鲜艳、不够苹果"；
而且方案 C 里的 24 小时条和起止时间只是可选项，不是必须保留的东西。
这一版改成一个**可调的配色台**，四个维度独立可选：

| 维度 | 选项 |
| --- | --- |
| 白班 × 夜班 | 日出 / 日月 / 昼夜 / 琥珀夜空 / 烈焰 / 蜜桃 / 金紫 / 珊瑚青 |
| 浓度 | 淡染 14% · 中等 32% · **浓 58%（推荐）** · 实心 100% |
| 形态 | 整格填色 / 格内胶囊 / 顶边色条 / 左侧色条 / 色点 |
| 格内元素 | 简称 · 工时 · 起止时间 · 时段条 · 完成点 · 节假日，逐个开关 |

选定后第 06 节直接输出浅色深色两套 Swift 色值，可以搬进 `AccentHex`。

## 文字色是算出来的，不是定死的

这一版的核心改动：**文字色随底色实时计算**。底色亮就把班次色往黑压，
底色暗就往白提，取第一个达到 4.6:1 的值。所以浓度从 14% 拉到 100%，
对比度始终守得住——页面里有一张实时的对比度表，低于 4.5:1 会标红。

现在代码里写死的 `.foregroundStyle(.white)` 是反面教材：
九个班次色刷白字全部不达标，systemYellow 上只有 1.51:1。

## 两条约束

- **白班和夜班必须在明度上也拉开**，不能只靠色相。两个色明度相同时，
  整月缩略图会变成一片均匀的花，轮转节奏就看不出来了。
- **休息和请假不占色位**，用 systemGray 家族，六个彩色位全留给工作班次。

# 方案 C 深化：苹果系统色（2026-09 第二版，已被第三版取代）

`palette-apple.html`。前一版的暖灰 + 奶油底被否掉了，这一版整体推倒重来，
只围绕 24 小时条（原方案 C）展开，配色全部建立在 iOS 系统色上。

- **五套配色**：系统色 / 柔彩 / 实心 / 单蓝 / 渐变
- **七种排版**：净白卡 / 淡染卡 / 顶边色条 / 粗条嵌字 / 时间环 / 无字纯条 / 刻度条
- 顶部控制条可切配色、密度、工时显隐、深浅色，七种排版同步重绘

## 配色的硬结论

苹果系统色**直接刷白字全部不达标**（实算）：

| 系统色 | 实心 + 白字 | 淡染底 + 同色深阶字 |
| --- | --- | --- |
| systemYellow `#FFCC00` | 1.51:1 | 4.86:1 |
| systemOrange `#FF9500` | 2.20:1 | 4.74:1 |
| systemMint `#00C7BE` | 2.12:1 | 4.61:1 |
| systemGreen `#34C759` | 2.22:1 | 4.79:1 |
| systemPink `#FF2D55` | 3.65:1 | 4.68:1 |
| systemIndigo `#5856D6` | 5.65:1 | 4.71:1 |

十二个系统色里只有 systemIndigo 能扛白字。苹果自己的做法是
**淡染底（色值 13% 覆在白底上）+ 同一色相压暗到 4.6:1 当文字色**——
日历的事件块、提醒事项的清单色、备忘录的标签都是这一套。
非要上实心块就用黑字：systemOrange 上黑字 9.55:1，systemYellow 13.89:1。

## 色相顺序

班次色位固定为 **橙 → 靛 → 薄荷 → 粉 → 紫 → 绿**
（白班 / 夜班 / 早班 / 中班 / 晚班 / 其他）。这个顺序过了色盲分离度校验：
相邻色对 OKLab ΔE 最差 14.4（门槛 8），普通视觉最差 24.7（门槛 15）。
苹果系统色本身没做过这项校验，换个顺序就会挂——比如粉和绿相邻只有 6.5。

休息、请假用 systemGray 家族 + 空心条，不占色位。

## 24 小时条规格

轴固定 00:00–24:00 不缩放；6/12/18 三条 1px 刻度；跨午夜断成
`[start,24:00]` 与 `[00:00,end]` 两段同色；休息日轨道透明 + 1px 内描边；
条高标准 5px；格宽小于 44pt 时刻度版自动退回连续条。

底色用 `systemGroupedBackground` 一族（浅 `#F2F2F7` + 白卡，
深 `#000` + `#1C1C1E`），不要自己调暖灰。
